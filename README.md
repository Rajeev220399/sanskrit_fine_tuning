# Sanskrit Text Generation using LSTM This project demonstrates 
**character-level Sanskrit text generation** using **TensorFlow and Keras**. 
The model learns Sanskrit character sequences from a corpus and generates new Sanskrit-style text. 
## Features - 
Sanskrit text preprocessing - Unicode character handling - Sequence generation using sliding windows - LSTM-based deep learning model - Temperature-based text generation - TensorFlow/Keras implementation 

## Tech Stack
Python
- TensorFlow / Keras
- NumPy
- Pandas
- Jupyter Notebook

## Model Architecture

Input → Embedding → LSTM → Dense → Softmax

Run
jupyter notebook notebooks/sanskrit.ipynb
